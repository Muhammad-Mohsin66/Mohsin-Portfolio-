# Muhammad Mohsin — Personal Portfolio

A modern, responsive, and high-performance personal portfolio website built with clean HTML5, CSS3, and JavaScript.

## 🚀 Live Preview
- **Developer**: Muhammad Mohsin
- **Specialization**: Full Stack Development • Python & FastAPI • Modern Web
- **Education**: Computer Science Student at COMSATS University Islamabad

## ✨ Features
- **Modern Obsidian Dark Design**: Styled with electric cyan & royal violet accents.
- **Ambient Canvas Background**: Lightweight native HTML5 canvas constellation particles without bulky external dependencies.
- **Dynamic Typewriter Effect**: Rotating specialization titles in the hero banner.
- **Interactive Project Filtering**: Instant category filtering for projects.
- **Full Responsiveness**: Mobile-first design with smooth sliding drawer navigation.
- **Direct Connect Channels**: Integrated LinkedIn, GitHub, and contact form handling.

## 🛠️ Tech Stack
- **Structure**: HTML5 (Semantic & Accessible)
- **Styling**: Vanilla CSS (Custom Design Tokens, Flexbox, CSS Grid, Glassmorphism)
- **Scripting**: Vanilla JavaScript (ES6+)
- **Icons & Typography**: Font Awesome 6, Outfit, Inter, Fira Code
